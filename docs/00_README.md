# Storage Account Audit Documentation

This directory contains audit documentation for the Azure Storage Account deployed via Terraform.

## Files Included
- 01_network_security_audit.md — Network access, firewall rules, VNet restrictions.
- 99_overall_storage_account_security_summary.md — Executive summary of findings.

## Scope
This audit currently covers:
- Network security controls
- Terraform configuration validation
- Azure Portal configuration verification

Additional audit domains (IAM, Logging, Monitoring) will be added later.
